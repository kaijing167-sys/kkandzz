# 星界守望

**[▶ 在线试玩《星界守望》（图鉴主页）](https://kaijing167-sys.github.io/kkandzz/)**  
**[🎮 直达第一章可玩塔防关卡（2.5D 魂系视角 · `science-era.html`）](https://kaijing167-sys.github.io/kkandzz/science-era.html)**

一本可以翻动的多元宇宙塔防图鉴。点击「开始游戏」展开星图，从目录选择一个平行宇宙，或使用书页底部的按钮逐页探索；在第一平行宇宙「科学纪元」点击「守护科学纪元」可直接进入 2.5D 俯瞰魂系可玩塔防关卡。

| 入口文件 | 说明 |
| --- | --- |
| `index.html` | 多元宇宙图鉴主页面，保留三张原画封面、电磁脉冲/山间流雾动效与页角卷曲翻书动画。 |
| `science-era.html` | 第一平行宇宙「科学纪元」2.5D 俯瞰魂系可玩塔防（四大学科塔、跨学科反应、6 波关卡与四阶段 Boss）。 |

| 平行宇宙 | 可以探索的内容 |
| --- | --- |
| 第一平行宇宙 · 科学纪元 | 在电磁光环下认识物理、化学、生物、计算机科学与技术四类防御塔，并可进入 2.5D 实机关卡。 |
| 第二平行宇宙 · 阴阳五行 | 在流云山水间对照阴阳两列，查看金、木、水、火、土与十天干的配属和纹样。 |

右上角的齿轮可调节音效音量和画面亮度，设置会保存在当前浏览器中。系统开启「减少动态效果」时，封面与翻页会采用静态显示。

## 本地试玩

下载并解压仓库，保留三张 PNG 封面、`index.html` 与 `science-era.html` 在同一目录，用浏览器打开 `index.html` 即可开始。在线试玩由 GitHub Pages 托管。
