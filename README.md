# 星界守望

**[▶ 在线试玩《星界守望》（原版图鉴）](https://kaijing167-sys.github.io/kkandzz/)**  
**[✨ 在线试玩《星界守望》新版（多页图鉴与动态微缩场景 · `v2.html`）](https://kaijing167-sys.github.io/kkandzz/v2.html)**  
**[🎮 直达第一章可玩塔防关卡（2.5D 等距视角 · `science-era.html`）](https://kaijing167-sys.github.io/kkandzz/science-era.html)**

一本可以翻动的多元宇宙塔防图鉴。点击「开始游戏」展开星图，从目录选择一个平行宇宙，或使用书页底部的按钮逐页探索。当前试玩版开放封面、图鉴、设置及第一平行宇宙「科学纪元」可玩塔防关卡。

| 试玩版本 | 入口文件 | 说明 |
| --- | --- | --- |
| 原版图鉴 | `index.html` | 保留三张原画封面、电磁脉冲/山间流雾动效与页角卷曲翻书动画。 |
| 新版独立试玩 | `v2.html` | 拆分为独立父子页面（含 `theme.css`、`universe-science.html`、`universe-wuxing.html`）与动态矢量微缩场景。 |
| 第一章可玩关卡 | `science-era.html` | 第一平行宇宙「科学纪元」2.5D 等距视角可玩塔防试玩版。 |

| 平行宇宙 | 可以探索的内容 |
| --- | --- |
| 第一平行宇宙 · 科学纪元 | 在电磁光环下认识物理、化学、生物、计算机科学与技术四类概念塔。 |
| 第二平行宇宙 · 阴阳五行 | 在流云山水间对照阴阳两列，查看金、木、水、火、土与十天干的配属和纹样。 |

右上角的齿轮可调节音效音量和画面亮度，设置会保存在当前浏览器中。系统开启「减少动态效果」时，封面与翻页会采用静态显示。

## 本地试玩

下载并解压仓库：
- 打开 `index.html` 试玩原版（需保留三张 PNG 封面在同一目录）；
- 或直接用浏览器打开 `v2.html` 试玩新版独立页面。

在线试玩由 GitHub Pages 托管。
